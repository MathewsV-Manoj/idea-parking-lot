# Idea Parking Lot

> For the ideas that arrive at the wrong time but still deserve a place to wait.

## How to use it

- Give each idea a short name and one sentence of context.
- Add a date if you might want to revisit it later.
- Choose one idea to explore only when you have the energy.

## A small note to yourself

Saving an idea is enough; you do not need to act on every spark.
